# Expense Tracker with Dashboard

A Python-based expense tracker that stores expenses in a CSV file and
visualizes spending using matplotlib.

## Features
- Add and view expenses
- CSV-based persistent storage
- Category-wise spending dashboard

## Tech Used
- Python
- matplotlib

## How to Run
```bash
pip install -r requirements.txt
python main.py
